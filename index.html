The Snake Game / Kepler-452B Terminator

Technology Used: Javascript, HTML, CSS, Netlify

Description: The Kepler-452B Terminator is an engaging web game controlled by the arrow keys (Up, Down, Left, Right). The game starts with a snake of two blocks in a 500x600 square arena. The player directs the snake to eat randomly appearing apples using the arrow keys. Each apple eaten makes the snake one block longer. The game is won when the snake fills the entire arena, and it's lost if the snake's head hits a wall, triggering a reset. The game begins when the user presses any arrow key, starting the apple-spawning process.

Snake Game Website Github Page

Annotation

I built this game using JavaScript, HTML, and CSS — every movement, collision, and grid calculation is driven by math and custom algorithm logic I wrote myself. To make it work, I had to solve coordinate systems, boundary detection, object growth patterns, and real-time keyboard event handling. This project shows that even a simple game demands precise algorithmic thinking and mathematical reasoning. It is the foundation of how I approach programming: break a problem into its rules, encode them precisely, and handle every edge case before the system can break.
