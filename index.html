SeaHoop

Technology Used: Swift, Firebase, Figma

SeaHoop Website Download Seahoop on the App Store Figma Design Github Repo For Website

Description: SeaHoop began from scratch as an idea drafted from pencil and paper, which services the Greater Seattle and the surrounding area. We are a group of basketball players committed to sharing basketball court information with those who want to play with others. At a time when the media seems to be dividing us, SeaHoop is working toward bringing hoopers together. SeaHoop provides daily court traffic statistics for over 100 different basketball locations in Seattle. Join us, download the app, and get involved in bringing the game we all love to your neighborhood by working together.

The Snake Game(Kepler-452B Terminator)

Technology Used: Javascript, HTML, CSS

Snake Game Website Github Page

Description: The Kepler-452B Terminator is an engaging web game controlled by the arrow keys (Up, Down, Left, Right). The game starts with a snake of two blocks in a 500x600 square arena. The player directs the snake to eat randomly appearing apples using the arrow keys. Each apple eaten makes the snake one block longer. The game is won when the snake fills the entire arena, and it's lost if the snake's head hits a wall, triggering a reset. The game begins when the user presses any arrow key, starting the apple-spawning process.
